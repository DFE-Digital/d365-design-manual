Standard developer tools
Tool Use it for
Power Platform CLI (opens in a new tab) The main tool for exporting and unpacking solutions into source control, working with Power Pages and connecting to environments
Azure DevOps Source control, pull requests, work items and the deployment pipelines. Request a licence through DfE's standard access process.
Visual Studio 2022 or later Building and debugging plugins and other C# components. Needs a Visual Studio licence.
Visual Studio Code Editing web resources, Power Pages code and configuration files, and working with the Power Platform CLI
Plugin Registration Tool Registering plugin steps in Dev only. Other environments get them through managed solutions.
XrmToolBox Optional. Specialist tasks such as exploring metadata, moving data, viewing plugin trace logs and bulk updates.
Postman Testing calls to the Dataverse Web API, custom connectors and integrations
