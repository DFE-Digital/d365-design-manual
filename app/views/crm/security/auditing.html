Microsoft explains how to set up auditing in Dataverse (opens in a new tab).

The standard

  • Turn on auditing for every table that holds business data, so creates, updates and deletes are recorded. Never turn it off on those tables.
  • Agree with the business owner which columns to audit, and don't audit columns that don't need it. Too much auditing affects performance and fills audit storage.
  • If the service needs to record who viewed sensitive data, use Microsoft Purview. Dynamics 365 auditing doesn't cover reading records.
  • Document which tables are audited and why.
  • Review audit logs regularly for unusual changes.
  • Keep audit logs only as long as they're needed, then delete them.
