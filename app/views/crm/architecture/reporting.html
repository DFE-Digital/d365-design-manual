Choose the reporting tool based on how complex the report is and how much data it uses.

Which reporting tool to use
Need Use
Simple operational reporting, such as lists, charts and team dashboards Dynamics 365 views, charts and dashboards
Reporting that is more complex, analytical or joins data from other systems Power BI (opens in a new tab), the standard DfE reporting tool
Large data sets, historical analysis or heavy processing Power BI connected to a copy of the data in Azure Data Lake, exported with Azure Synapse Link for Dataverse (opens in a new tab)

Standards

  • Don't run heavy or complex reports against production. Dynamics 365 is a transactional system, and those queries slow it down for users.
  • For large or complex reporting, connect Power BI to the Data Lake rather than to Dynamics 365.
  • Make sure reports follow the same data governance, security and retention rules as the service.
