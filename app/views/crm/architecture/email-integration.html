The standard

Server-side synchronisation with Exchange Online is the only approved way to connect Dynamics 365 to email. It sends and receives email between Microsoft services directly, so it doesn't depend on Outlook or a user's device.

Microsoft explains how to set up server-side synchronisation (opens in a new tab).

How to use it

  • Host every mailbox that connects to Dynamics 365 in Exchange Online.
  • Manage Dynamics 365 mailboxes centrally, not user by user.
  • Use shared mailboxes and queues for team email.
  • Set tracking rules so that only business correspondence is tracked against records, not every email.
  • Check mailbox alerts and synchronisation errors regularly.
  • Monitor email volumes, attachment sizes and retention.

What to avoid

  • Anything that depends on Outlook or a user's device
  • Setting up email integration separately for each user
  • The email router, or other retired Microsoft email technologies
